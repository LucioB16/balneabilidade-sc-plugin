This draft describes the handling of data by Balneabilidade SC, an independent, open-source, read-only MCP service maintained through the LucioB16 GitHub repository. It is not operated or endorsed by IMA/SC.

Service operator: Lucio Bottacin.

1. What the service receives

When a user invokes a tool, the MCP server receives only the task parameters sent by the client: a beach name, municipality, sampling-point identifier, selected dates, result limit or bulletin page. These fields are used to find published water-sampling data. We do not request account credentials, payment details, government IDs or full chat transcripts.

Hosting and network providers may also process technical connection information (such as IP address, request timestamp, HTTP headers and error data) to deliver, secure and troubleshoot the service. Enzonic support stated that data is not retained but did not itemize the fields that may be processed temporarily.

2. Why the data is processed

Task parameters are processed to look up and return dated IMA/SC bulletins, sampling points, historical results and bulletin images. Technical metadata may be used by infrastructure providers for routing, availability, abuse prevention and operational security.

3. Storage and retention

The MCP application has no user accounts or conversation database. It does not intentionally retain tool arguments or complete conversations. Uvicorn access logging is disabled; application-level tool-error logging records the exception type rather than the request body.

To reduce requests to the official source, the application caches public IMA/SC documents, not user profiles: index and analyses (1 hour), sampling-point catalog (24 hours), current-year history (6 hours), older-year history (30 days), and downloaded bulletin PDFs (up to 3,650 days by cache expiration settings). These are cache validity periods; expired files may remain on disk until cleared or the ephemeral runtime storage resets.

Hosting provider confirmation: in an email response to an inquiry about this public MCP server and log retention, Enzonic support confirmed this use of the free plan and stated: “Data is not retained.” The reply did not specify individual categories of data or any independent network providers' logs. This statement does not exclude transient processing required to operate the network and does not describe the application's separate cache of public documents.

4. Who receives data

Enzonic provides hosting and may rely on infrastructure subprocessors. The MCP service requests public-source information from IMA/SC. This legal website is prepared for GitHub Pages, which may process visits to its pages. The ChatGPT/Codex platform separately handles conversations and tool invocations under its own terms. No third-party advertising or analytics code is included in these pages or in the MCP application.

5. User choices and privacy requests

Users can stop calling these tools or disconnect the plugin through their client. Do not enter private or sensitive information in beach-search parameters. Platform-side chat storage is controlled by the platform, not this MCP server.

For general questions, use GitHub Issues. GitHub Issues are public; never publish personal information or sensitive requests there. To make a privacy-related request, contact Lucio Bottacin directly by email: luciobotacin@gmail.com. Rights of access, correction, deletion or objection may apply under relevant law, subject to what data is actually held.

6. Changes and scope

This notice covers only the independent Balneabilidade SC project, not IMA/SC, Enzonic, GitHub or OpenAI services. Changes will be reflected here with a revised date. Published readings are not live environmental measurements.
