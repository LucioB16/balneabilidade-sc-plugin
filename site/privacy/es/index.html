Política de privacidad

PortuguêsEnglishEspañol

Última actualización: 17/11/2026

Borrador para revisión — todavía no aprobado para el directorio público.

Este borrador describe el tratamiento de datos de Balneabilidade SC, un servicio MCP independiente, de código abierto y de solo lectura, mantenido en el repositorio de GitHub LucioB16. No pertenece al IMA/SC ni cuenta con su respaldo.

Responsable del servicio: Lucio Bottacin.

1. Datos recibidos

Cuando se invoca una herramienta, el servidor recibe únicamente los parámetros enviados por el cliente: nombre de la playa, municipio, identificador del punto de muestreo, fechas, cantidad de resultados o página del boletín. No solicitamos credenciales, datos de pago, documentos de identidad ni conversaciones completas.

Los proveedores de hosting y red pueden procesar datos técnicos de conexión (por ejemplo, dirección IP, fecha y hora, encabezados HTTP y errores) para brindar y proteger el servicio. No están verificados los campos exactos que registra Enzonic para esta instancia.

2. Finalidades

Los parámetros permiten buscar y devolver boletines fechados del IMA/SC, puntos de muestreo, históricos e imágenes. Los proveedores de infraestructura pueden tratar metadatos técnicos para ruteo, disponibilidad, prevención de abuso y seguridad.

3. Almacenamiento y conservación

El servidor MCP no tiene cuentas de usuarios ni base de datos de conversaciones. La aplicación no guarda deliberadamente argumentos de herramientas ni chats completos. El registro de accesos de Uvicorn está desactivado y el registro de errores guarda el tipo de excepción, no el cuerpo de la solicitud.

Para reducir solicitudes al origen, se mantiene una caché de documentos públicos del IMA/SC, no perfiles: índice y análisis (1 hora), catálogo de puntos (24 horas), historial del año actual (6 horas), historial de años anteriores (30 días) y PDF de boletines (validez de hasta 3650 días). Esos plazos son de validez de caché; los archivos vencidos pueden permanecer hasta su limpieza o el reinicio del almacenamiento temporal.

Todavía no está confirmado el período de conservación de los registros de infraestructura. Enzonic y sus proveedores de red pueden guardar metadatos técnicos según sus políticas. Hay que verificar esos plazos antes de presentar el plugin al directorio público.

4. Destinatarios

Enzonic aloja el servicio y puede utilizar subprocesadores. El MCP consulta datos públicos del IMA/SC. Este sitio legal está preparado para GitHub Pages, que puede tratar metadatos de visita. ChatGPT/Codex trata las conversaciones y las llamadas a herramientas bajo sus propias condiciones. No incorporamos scripts publicitarios ni analítica de terceros en el sitio o la aplicación.

5. Controles y solicitudes

Podés dejar de usar las herramientas o desconectar el plugin desde tu cliente. Evitá introducir datos privados o sensibles en las búsquedas. La conservación del historial de chat depende de la plataforma.

Para consultas generales, utilizá GitHub Issues. Las incidencias son públicas: no publiques información personal ni solicitudes sensibles. Para solicitudes de privacidad, escribile directamente a Lucio Bottacin: luciobotacin@gmail.com. Pueden corresponder derechos de acceso, rectificación, eliminación u oposición según la ley aplicable y los datos realmente conservados.

6. Cambios y alcance

Este aviso se limita al proyecto independiente Balneabilidade SC y no cubre los servicios del IMA/SC, Enzonic, GitHub u OpenAI. Los cambios se identificarán con una fecha nueva. Los resultados publicados no son mediciones ambientales en tiempo real.
