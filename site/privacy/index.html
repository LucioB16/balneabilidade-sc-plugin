Política de Privacidade

PortuguêsEnglishEspañol

Última atualização: 17/11/2026

Minuta para revisão — ainda não aprovada para publicação no diretório.

Esta minuta descreve o tratamento de dados pelo Balneabilidade SC, serviço MCP independente, de código aberto e somente leitura, mantido no repositório GitHub LucioB16. Não é operado nem endossado pelo IMA/SC.

1. Dados recebidos

Ao utilizar uma ferramenta, o servidor recebe apenas os parâmetros enviados pelo cliente: nome da praia, município, identificador do ponto de coleta, intervalo de datas, limite de resultados ou página de boletim. Não solicitamos credenciais, dados de pagamento, documentos de identidade nem o histórico completo das conversas.

Os provedores de hospedagem e rede podem tratar metadados técnicos (como IP, data e hora, cabeçalhos HTTP e erros) para entregar, proteger e diagnosticar o serviço. Os campos efetivamente registrados pela Enzonic nesta instância não foram confirmados.

2. Finalidades

Os parâmetros são usados para consultar e retornar boletins datados do IMA/SC, pontos de coleta, histórico e imagens de boletins. Dados técnicos podem ser utilizados por provedores de infraestrutura para roteamento, disponibilidade, prevenção de abuso e segurança.

3. Armazenamento e retenção

O servidor MCP não possui contas de usuários nem banco de dados de conversas. A aplicação não armazena intencionalmente argumentos das ferramentas ou conversas completas. O registro de acesso do Uvicorn está desativado; erros das ferramentas são registrados apenas pelo tipo da exceção, sem o corpo da solicitação.

Para reduzir acessos à fonte oficial, existe cache de documentos públicos do IMA/SC, não de perfis de usuários: índice e análises (1 hora), catálogo (24 horas), histórico do ano corrente (6 horas), histórico de anos anteriores (30 dias) e PDFs de boletins (prazo de validade de até 3.650 dias). Esses prazos são de validade do cache; arquivos expirados podem permanecer até a limpeza ou a reinicialização do armazenamento temporário.

O prazo de retenção dos logs de infraestrutura ainda não foi confirmado. Enzonic e provedores de rede podem conservar metadados técnicos conforme suas políticas. Esse prazo precisa ser apurado antes de enviar o plugin ao diretório público.

4. Destinatários

A Enzonic hospeda o serviço e pode utilizar subprocessadores de infraestrutura. O MCP consulta dados públicos publicados pelo IMA/SC. Este site legal foi preparado para o GitHub Pages, sujeito ao tratamento técnico do GitHub. A plataforma ChatGPT/Codex trata conversas e chamadas de ferramentas segundo suas próprias regras. Não incluímos scripts de publicidade ou análise de terceiros neste site ou na aplicação MCP.

5. Controle do usuário e solicitações

O usuário pode deixar de usar as ferramentas ou desconectar o plugin no cliente. Não envie dados pessoais ou sensíveis nos parâmetros de busca. A retenção de conversas no cliente é controlada pela própria plataforma.

Para dúvidas gerais, use as Issues do GitHub. As Issues são públicas: não publique dados pessoais nem pedidos sensíveis. Antes do lançamento público, é necessário confirmar um canal confidencial para solicitações de privacidade. Direitos de acesso, correção, eliminação e oposição podem ser aplicáveis conforme a legislação e os dados efetivamente mantidos.

6. Alterações e escopo

Este aviso se aplica apenas ao projeto independente Balneabilidade SC, não aos serviços do IMA/SC, Enzonic, GitHub ou OpenAI. As alterações serão informadas com nova data. Os resultados divulgados não são medições ambientais em tempo real.
